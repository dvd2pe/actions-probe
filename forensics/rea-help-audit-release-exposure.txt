rea audit-release-exposure — Report what static analysis of a shipped artifact recovers. Reads the selected path. When the selection is a file, the parent directory is listed for sibling .pdb, .dSYM, .debug, and .map debug companions.

Usage: rea audit-release-exposure <path> [options]

Arguments:
  path  Shipped .app bundle, install directory, ASAR, or executable

Options:
  --max-file-bytes <value>     Selected-file, on-disk PE, and shared packaged-image read ceiling. Text, source-map, and other package members use the smaller allowances in coverage.allowances. (default: 268435456)
  --fail_on <high|medium|low>  Completed audit exits 3 when an exposed check meets this severity. Unknown and unassessed checks do not.

Custom Global Options:
  --timings  Write measured command timing to stderr.

Global Options:
  --filter-output <keys>                      Filter output by key paths (e.g. foo,bar.baz,a[0,3])
  --format <toon|json|yaml|md|jsonl|csv|tsv>  Output format
  --full-output                               Show full output envelope
  --help                                      Show help
  --json                                      Shorthand for --format json
  --llms, --llms-full                         Print LLM-readable manifest
  --schema                                    Show JSON Schema for command
  --token-count                               Print token count of output (instead of output)
  --token-limit <n>                           Limit output to n tokens
  --token-offset <n>                          Skip first n tokens of output
